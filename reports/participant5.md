## Сценарий 3: Масштабный рефакторинг - Не работает

**Запрос:** "Проведи рефакторинг @stack/ : улучши именование и добавь документацию в виде комментариев."

| Параметр | Значение |
|----------|----------|
| Статус | ❌ Не работает |
| Инструменты | `read_directory`, `read_file`, `edit` |
| Авто-применение | ❌ нет (изменения не были применены) |
| Ошибки инструментов | `edit`: файл не был прочитан в текущей сессии |
| Завершение | ❌ цикл повторных действий (Agentic loop), остановлен системой |

**Проблемы:**
1. Модель генерирует изменения до фактического редактирования файла, смешивает этапы "подготовка результата" и "выполнение операции".
2. **Отсутствие проверки зависимых файлов:** Модель изменила API функций `stack.c`, однако не проверила связанные файлы.
3. **Ошибка порядка вызова инструментов:** Модель попыталась выполнить действие редактирования без подтвержденного чтения файла в текущей сессии.
4. **Повторение ошибочного действия вместо восстановления**: После ошибки модель правильно определила проблему, однако дальнейшее поведение стало нестабильным (модель несколько раз подтверждала успешность изменения без проверки точности совпадения по `old_string` и `new_string`) и запрос ушел в agentic loop.

## Сценарий 4: Использование Subagents для анализа проекта - Частично работает

**Запрос 1:** "Проанализируй весь проект, найди потенциальные проблемы и предложи исправления."

| Параметр | Значение |
|----------|----------|
| Статус | ⚠️ Частично работает |
| Инструмент | `agent`, `subagent_type: Explore` |
| Количество запусков Subagent | Несколько последовательных запусков |

**Проблемы:**
1. **Повторный запуск Subagent без необходимости:** Отсутствует механизм проверки, был ли анализ уже выполнен.
2. **Отсутствует агрегация результатов Subagents:** Результаты предыдущих агентов не используются повторно.
3. **Генерация недостоверных рекомендаций при повторных запусках:** Помимо полезных рекомендаций были сгенерированы шаблонные, не связанные с реальным проектом.
