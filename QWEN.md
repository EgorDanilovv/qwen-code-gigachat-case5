# Контекст проекта

## Окружение
- Операционная система: Windows 11
- Язык проекта: JavaScript (НЕ TypeScript)
- Пакетный менеджер: npm
- Тестовый фреймворк: Jest
- НЕ используй body-parser — используй встроенный express.json()

## Правила кода
- Все комментарии — на русском языке
- Используй современный синтаксис ES6+
- Избегай устаревших пакетов
- Всегда проверяй типы входных данных

## При генерации тестов
- Покрывай ВСЕ функции из исходного файла
- НЕ используй toThrowErrorMatchingSnapshot
- Используй toThrow(Error) или toThrow('сообщение')
- Для каждой функции минимум 3 теста

## При чтении файлов
- Перед ответом убедись, что прочитал ВЕСЬ файл
- Перечисли все функции/классы, которые нашёл
- Если функций больше, чем ты обработал — вернись и обработай остальные
